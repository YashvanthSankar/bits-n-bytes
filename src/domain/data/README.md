# Country boundary data

`india.geojson.json` is the full geoBoundaries gbOpen IND ADM0 MultiPolygon, pinned to upstream commit `9469f09`. Source: [geoBoundaries download](https://github.com/wmgeolab/geoBoundaries/blob/9469f09/releaseData/gbOpen/IND/ADM0/geoBoundaries-IND-ADM0.geojson); [metadata](https://www.geoboundaries.org/api/current/gbOpen/IND/ADM0/).

License: CC0 1.0 public domain. Boundary ID: IND-ADM0-67634026; source year 2014; 34 polygons, 2,082 vertices, including island polygons. Original bytes SHA-256: `77fb5cb03be9970e638fa38d1bd6a377ea7e158b4dfd1a511067925442233443`.

This is an approximate operational coverage boundary, not a government-certified boundary or a statement about disputed territory. A point alone cannot admit a tourist: the entire reported accuracy circle must lie within the polygon. Touching a boundary returns uncertain. More detailed current jurisdiction data and boundary-resolution review remain release requirements; GPS accuracy does not measure dataset accuracy.
