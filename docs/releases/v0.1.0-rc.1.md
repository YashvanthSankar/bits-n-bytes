## Install and test

Download the APK from the GitHub prerelease, allow installation from your browser/file manager, then open GudTour without Metro or Expo Go. Android may ask to replace an existing install; a differently signed development install must be removed first. Production accounts start separately from development.

1. Google login, India/location gate, language selection, profile save, sign-out and sign-in.
2. Android map renders with location; refresh location and browse incidents/shelters.
3. Use two different Google accounts to report the same incident independently. Check corroboration separately from Jev qualification and authority verification.
4. Approved account opens Authority workspace → View reports → LIVE reports. Inspect original Jev result and saved context.
5. For controlled emergency testing, explicitly enable DEMO mode in Settings on each test recipient, use the approved DEMO authority workspace, and keep both clients open with current positions inside the published area.
6. Verify alert receive/open/dismiss/reopen, original instructions and language translation. Test an outside-area client too.
7. Browse SACHET latest alerts and full original notices. Maintain a DEMO shelter and verify raw nearest ordering.

Alerts are custom in-app notifications. Closed-app push, SOS dispatch, safe routing, offline basemaps, nearby chat, emergency contact maintenance and the remaining recovery/privacy/release gates are not complete. Reports remain unverified/corroborated unless an authority verifies them; a model decision is not official verification.
